# Nathnael Ashenafi — Portfolio

My personal portfolio built with React and Tailwind. Showcases my projects, skills, certificates, and experience as a Computer Science student and developer.

![Portfolio Preview](./public/images/preview.png)

## What's Inside

- Hero with intro and CTAs
- About section with quick highlights
- Journey timeline
- Skills grid with click-to-expand details
- Projects showcase
- Certificates with popup viewer
- Experience section
- Contact form that sends emails directly to my inbox
- Dark mode toggle
- Fully responsive

## Built With

- **React** — component structure and state
- **Tailwind CSS** — styling
- **Framer Motion** — animations
- **EmailJS** — contact form email delivery
- **Lucide React** — icons
- **Vite** — dev server and build tool
